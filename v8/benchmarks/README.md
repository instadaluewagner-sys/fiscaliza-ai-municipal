# Benchmark V8

Este diretório receberá o gabarito humano dos processos usados para validar o Fiscaliza.AI.

Cada processo deverá registrar, no mínimo:

- identificação do processo;
- natureza/origem da contratação;
- documentos autônomos e páginas;
- objeto e quantidade quando existentes;
- notificação/intimação;
- defesa;
- parecer técnico;
- parecer jurídico;
- relatório conclusivo;
- decisão;
- estágio processual;
- próximo ato esperado.

O gabarito deve ser produzido por conferência humana. O motor da V8 será comparado contra ele; não criaremos regras específicas para um único processo.
